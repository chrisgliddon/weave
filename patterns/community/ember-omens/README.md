# Ember Omens

Ember Omens is the original MIT-licensed reference package for Weave community package format 1. It contains four weighted, reversible firelight signs and one three-position spread. It has no external assets or executable code.

Validate it:

```bash
cargo run -p weave-patterns --bin weave-pattern -- \
  validate patterns/community/ember-omens/package.weave-pattern.json
```

The complete publication, installation, version-selection, story-compilation, provenance, and moderation workflow is in the [community package guide](../../../docs/community_patterns.md).
