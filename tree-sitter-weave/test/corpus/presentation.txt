==================
Scene and stage declarations with presentation cues
==================

scene ferry_dusk {
    background: "art/ferry_dusk.png"
    fit: contain
    anchor: 0.5, 0.35
}

stage mara {
    image: "art/mara_neutral.png"
    name: "Mara"
    slot: left
    layer: 1
    variant surprised {
        image: "art/mara_surprised.png"
    }
}

=== start ===
@scene ferry_dusk
@show mara
@speaker mara
@move mara center
@swap mara surprised
@transition fade 240
The ferry leaves at dusk.
@hide mara
@speaker
After she leaves.
-> END
