# Contributing

The canonical [CONTRIBUTING.md](https://github.com/chrisgliddon/weave/blob/main/CONTRIBUTING.md) defines development setup, pull-request expectations, quality gates, and exact structured templates for Features, Improvements, and Bugs.

Before starting a large language, serialized-format, runtime, API, or editor change, search existing issues and open one focused proposal. Public reports, logs, fixtures, and screenshots must replace every secret or credential value with `[REDACTED]`.

Suspected vulnerabilities do not belong in a public issue. Follow the [security page](security.md) instead.
